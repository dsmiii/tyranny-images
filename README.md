# Портреты «Тирании драконов»

Хостинг картинок для базы кампании в buildin.ai.

Файлы отдаются напрямую по адресам вида:

```
https://raw.githubusercontent.com/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ/main/имя.jpg
```

Через CDN — быстрее и с кэшированием:

```
https://cdn.jsdelivr.net/gh/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ@main/имя.jpg
```

## Что здесь лежит

Портреты NPC, уменьшенные до 400 пикселей по ширине и пережатые в JPEG. Оригиналы хранятся отдельно, в основном репозитории кампании они не публикуются.

Имена файлов — транслитерация имён персонажей: `aya-glenmiir.jpg`, `ektor-brams.jpg`. Соответствие ведётся в основном репозитории, в файле `90 Служебное/Портреты/адреса.tsv`.

## Как обновлять

Новые портреты готовятся скриптом в основном репозитории:

```
python "90 Служебное/портреты.py" --выгрузка
```

Файлы появляются в папке `Портреты/для-загрузки/` — их и нужно залить сюда. Дальше:

```
python "90 Служебное/портреты.py" --гитхаб ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ --адреса
```

Адреса разойдутся по заметкам хранилища.

## Почему репозиторий публичный

`raw.githubusercontent.com` отдаёт файлы приватного репозитория только с токеном — вставить такую ссылку в buildin нельзя. Поэтому картинки лежат отдельно и открыто, а весь текст кампании остаётся в приватном репозитории.

Здесь только изображения. Ни имён, ни описаний, ни сюжета.
